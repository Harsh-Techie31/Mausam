# Mausam - Your Personal Weather App

Mausam is a **real-time weather application** built with **Flutter**, designed to provide accurate weather forecasts based on your location. It features **automatic location detection**, a **searchable city weather view**, and real-time weather updates using the **OpenWeather API**.

## 🚀 Features

### 🌍 Location-Based Weather
- Automatically detects your location using **Geolocator**.
- If location permission is denied, it defaults to **New Delhi**.

### 🔍 Search for Any City
- Tap on the city name to **search for any location**.
- Get real-time weather updates for the searched city.

### ☀️ Real-Time Weather Updates
- Fetches real-time temperature, humidity, wind speed, and more.
- Uses **OpenWeather API** to ensure accurate forecasts.

### 🕒 Hourly Weather Forecast
- Displays **hourly forecasts** for the next 24 hours.
- Provides temperature, precipitation, and wind conditions.

### 🎨 Beautiful & Responsive UI
- A clean and modern design with an intuitive experience.
- Works smoothly across all devices.

## 🛠️ Tech Stack

### Frontend (Flutter)
- **State Management:** Provider
- **Location Handling:** Geolocator
- **Networking:** HTTP Package
- **API Integration:** OpenWeather API
